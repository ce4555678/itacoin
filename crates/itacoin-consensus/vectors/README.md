# aserti3-2d test vectors

Official Bitcoin Cash `aserti3-2d` vectors, copied unchanged from
<https://gitlab.com/bitcoin-cash-node/bchn-sw/qa-assets/-/tree/master/test_vectors/aserti3-2d>.
They use Bitcoin Cash parameters (600 s spacing, 2-day half-life, compact
`nBits` targets) and prove that `itacoin-consensus::next_target` is the same
algorithm before ITACOIN parameters are applied.
